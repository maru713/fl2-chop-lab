# FL2カット軌道ラボ

フェイントロング2（粒高）でのカット・ツッツキの軌道と回転を計算・アニメーション表示するシミュレーター。

- `index.html`：軌道シミュレーター（相手の打球、スイング、粒の倒れ方の仮説モード、ぶれに強い振り方の探索）
- `attack.html`：攻撃編（グレイザー09C 厚でのドライブ・スマッシュ。相手のカット・ナックル・ツッツキ・高い球）
- `receive.html`：レシーブ編（横・下・上回転のサーブを09CとFL2でレシーブ。上から・横から見た3次元の軌道と、入る面の向きマップ）
- `serve.html`：サーブ編（トスしたボールへのラケットの当て方から、回転・打ち出し・台の上の軌道を計算。欲しい回転から当て方を逆算するモードもある。結果はレシーブ編に渡せる）
- `grip.html`：ラバーが「つかむ」仕組みの図解
- `js/physics.js`：3ページ共通のつかむ強さの表と空気力学
- `js/flight3d.js`：レシーブ編とサーブ編で共通の3次元の飛び方・台での弾み・ラケットとの接触
- `js/side-view.js`：カットと攻撃編で共通の、横から見た図・人・ラケット・手元ルーペ。拡大表示の縮尺（`zoomScale`）はここで決めていて、どのページでも同じになる

計算は簡略化したモデルで、粒がボールをつかむ強さや反発などはFL2の実測値ではなく仮定の値です。結果は傾向として見てください。

`js/` のファイルを変えたら、各HTMLの `<script src="js/...?v=...">` の `v=` の値を変えてください（スマホのブラウザが古いJSを使い続けないようにするため）。
