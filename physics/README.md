# 粒の物理モデル（rubbersim.py）

FL2 OX の粒を1本ずつ「縮むばね＋曲がるばね」でつないだ柱として扱い、ボールが当たって離れるまでを 0.2 µs 刻みで計算します（numba 使用）。

- 粒：高さ1.8 mm・直径1.65 mm・間隔2.15 mm（ITTFの細長さの上限1.1に近い）。せん断変形を含む横剛性から座屈荷重を求め、実際の幾何で計算するので、押す力が大きいと粒が倒れる。
- 粒の初期のばらつき：傾き約2°（乱数）
- 先端の摩擦：クーロン摩擦＋接線ばね（付着とすべり）
- ボール：剛体球（2.7 g, 半径20 mm）＋粒ごとの接触ばね

`keff_tables.json` は、面を押す速さ（vn）と面に沿ってこすれる速さ（u）ごとの「つかむ強さ（k_eff）」の表で、摩擦係数 0.5/0.8/1.0、ゴムの硬さ（ヤング率）1.5/2.5/4.0 MPa の9通り。さらに、薄（1.1mmスポンジ、ヤング率0.6MPaと仮定）の9通りを `S11_` 付きのキーで追加。シミュレーターはこの表を補間して使う。

限界：ボールの殻の変形やラケット本体の損失は入っていないので、反発（COR）は過大。シミュレーター側では反発を別の値で与えている。材料定数（摩擦係数・ゴムの硬さ）は実測がなく、プレーヤーの体感と合う値（摩擦0.5）を推奨値にしている。

# 裏ソフトの物理モデル（invertedsim.py）

表面のシートを1 mm角の点に分け、1点ずつスポンジの柱（縦ばね k=E·A/t、横ばね G=E/3、つぶれると硬くなる）と隣の点（シートの張り E_t·t_t）でつないで、ボールが当たって離れるまでを 0.1 µs 刻みで計算します。シートが横にたわんで戻る弾き（回転の反転）もこの中で起きます。

- 校正：裏ソフトに 14 m/s・下回転66回転/秒で 0°/30°/60° に当てた実測（Applied Sciences 2019）に、接触の損失 zc・スポンジの減衰 ζs・摩擦係数 μ を合わせた（`inverted_calib.json`：zc=1.936, ζs=0.244, μ=1.01）。反発の差 ±0.03、回転比の差 ±0.07 以内。
- `G9`（グレイザー09C 厚）：スポンジ 1.9 mm（スプリングスポンジX・硬度42）、微粘着として μ×1.3、粘着力 50 kPa。
- `INV`（非粘着テンション系）：スポンジ 2.1 mm、粘着なし。
- `keff_tables.json` の `G9`/`INV` は `k`（つかむ強さ、弾きを含む）と `e`（法線方向の反発）の2つの表を持つ。シミュレーターではこの2つを補間して使い、弾き・回転保持の別パラメータは使わない。

限界：実測ラバーの銘柄は不明、校正点は 14 m/s の1点だけ、スポンジのヤング率 1.8 MPa と粘着の強さは仮定。
